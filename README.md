# Assignment-1

Assignment-1 is a responsive web design project built with HTML and CSS. The project focuses on creating a clean, modern, and user-friendly interface that works across different screen sizes.

## ✨ Features

- Responsive web design
- Clean and modern user interface
- Mobile-friendly layout
- Tablet and desktop responsive layout
- Structured HTML markup
- Custom CSS styling
- Responsive images and sections
- Smooth and user-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📱 Responsive Design

The website is designed to provide a consistent user experience across different devices, including:

- 📱 Mobile
- 📱 Tablet
- 💻 Laptop
- 🖥️ Desktop
